BARÇA COMPANION — HOME SCREEN ICON FIX

This package fixes mismatched icon filenames in index.html and manifest.json.
It retains the JavaScript source and bundle from the previous Google Stats Link update.

Install all files together in the same published app folder, replacing matching files:
- index.html
- manifest.json
- bundle.min.js
- icon-180.png
- icon-192.png
- icon-512.png

Then on the iPad:
1. Open the app website in Safari and refresh it.
2. Remove the old Barça Companion home-screen shortcut.
3. Open Share > Add to Home Screen again.
4. If the old icon still appears, close Safari and reopen the site before adding it again.

The icon cache may take a little time to update. This package does not change app layout or stats behavior.
